# SGCL-DPI: Structure-Guided Curriculum Learning for Drug–Protein Interaction Prediction

**SGCL-DPI** is a deep learning framework for predicting drug–protein interactions (DPIs). It integrates structural similarity graphs with graph neural networks, using curriculum learning to improve generalization and predictive performance.

This repository contains the implementation of SGCL-DPI, which combines:
- Graph Neural Networks (GNNs) for molecular and protein feature extraction.
- Structure-guided similarity graphs for both drugs and proteins.
- Curriculum learning strategies for staged training with increasing difficulty.

## 🧩 Feature Preparation

Before running the model, you must generate three essential input files:

1. **`features.pkl`** – a file containing the computed similarity features.
2. **`drug_similarity_sample.csv`** – drug similarity graph file.
3. **`protein_similarity_sample.csv`** – protein similarity graph file.

All scripts required for generating these files are located in the `simgraphmaker/` directory.

---

### 🔹 Step 1: Generate `features.pkl`

Navigate to the `simgraphmaker` directory and run:

cd simgraphmaker
python simgraphmaker.py


### 🔹 Step 2: Generate Drug and Protein Similarity Graphs

This step creates structural similarity graphs for both drugs and proteins, which guide the model’s learning process. You need to run two scripts located in the `simgraphmaker/` directory.

Run the following commands:

cd simgraphmaker
python feature_similarity_computer.py
python similarity_threshold_processor.py

What Each Script Does:
feature_similarity_computer.py
Computes pairwise similarity scores based on the extracted features of drugs and proteins.

similarity_threshold_processor.py
Applies a thresholding strategy to retain only the most relevant similarities and formats the output into graph-compatible CSV files.

Output Files:
drug_similarity_sample.csv

protein_similarity_sample.csv

## 🚀 Running the Model

After completing feature preparation and ensuring that the following files exist:

- `features.pkl` (generated by `simgraphmaker.py`)
- `drug_similarity_sample.csv` and `protein_similarity_sample.csv` (generated by the similarity graph scripts and placed under `Data/SimilarityGraphs/`)

you can run the SGCL-DPI model.

Navigate to the `gcns/` directory and execute the training script:

cd gcns
python sgcl_dpi.py

This script will train the SGCL-DPI model using the prepared features and similarity graphs. During execution, the script will:

Load molecular and protein feature data

Construct drug and protein graphs

Apply curriculum learning with structure-guided sampling

Train and evaluate the model using cross-validation

Performance metrics such as F1-score, AUC-ROC, and AUPR will be printed and saved for further analysis.
